# FOSSBilling易支付插件
FOSSBilling的易支付插件

项目简介
本项目为FOSSBilling提供易支付平台的支付网关扩展，支持支付宝和微信支付。通过此扩展，您可以在FOSSBilling系统中轻松集成易支付平台的收款功能。

功能列表
✅ 支付宝支付 - 通过易支付平台完成支付宝收款
✅ 微信支付 - 通过易支付平台完成微信收款
✅ 自动处理支付回调 - 自动验证交易状态并更新订单
✅ 签名验证 - 严格验证支付通知的真实性，确保交易安全
✅ 客户余额自动充值 - 支付成功后自动为客户账户充值

安装要求
FOSSBilling 0.7.x
PHP 8.2+
支持的易支付平台版本：最新版
配置教程
配置支付宝支付网关
登录FOSSBilling管理后台
导航至 Configuration → Payment gateways
点击 新建支付网关
选择 易支付-支付宝 by empet 作为网关类型
填写配置项：
易支付网关地址: 您的易支付平台地址 (例如: https://your-epay-domain.com)
商户ID: 您在易支付平台的商户ID
商户密钥: 您在易支付平台的商户密钥
点击 启用 并保存
配置微信支付网关
登录FOSSBilling管理后台
导航至 Configuration → Payment gateways
点击 新建支付网关
选择 易支付-微信支付 by empet 作为网关类型
填写配置项：
易支付网关地址: 您的易支付平台地址 (例如: https://your-epay-domain.com)
商户ID: 您在易支付平台的商户ID
商户密钥: 您在易支付平台的商户密钥
点击 启用 并保存
使用说明
当客户下单后，可以选择支付宝或微信支付方式
点击支付按钮，系统会自动跳转到易支付平台的支付页面
客户完成支付后，系统会自动处理支付结果
支付成功后，客户账户余额会自动充值，订单状态更新为已支付
常见问题
Q1: 支付成功后订单状态没有更新怎么办？
A: 请检查以下几点：

确认易支付平台的异步通知地址能够被公网访问
检查服务器防火墙是否阻止了易支付平台的回调请求
查看FOSSBilling日志文件 (/path/to/fossbilling/data/log/application.log) 中是否有错误信息
Q2: 如何测试支付功能？
A: 您可以使用易支付平台提供的测试环境进行测试，通常测试模式下可以使用固定金额 (如0.01元) 进行支付测试。

Q3: 支持其他支付方式吗？
A: 本扩展目前支持支付宝和微信支付。如果您需要其他支付方式，可以参考现有代码进行扩展，或联系开发者提供定制服务。
