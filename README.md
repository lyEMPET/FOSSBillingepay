# FOSSBilling易支付插件
FOSSBilling的易支付插件


![FOSSBilling](https://fossbilling.org/assets/images/logo-dark.svg)

> **注意**: 本项目是基于 [xkatld/FOSSBilling-Patch](https://github.com/xkatld/FOSSBilling-Patch) 修改而来，保留了原项目的全部功能，并增加了微信支付支持。

## 项目简介

本项目为FOSSBilling提供易支付平台的支付网关扩展，支持支付宝和微信支付。通过此扩展，您可以在FOSSBilling系统中轻松集成易支付平台的收款功能。

## 功能列表

- ✅ **支付宝支付** - 通过易支付平台完成支付宝收款
- ✅ **微信支付** - 通过易支付平台完成微信收款
- ✅ **自动处理支付回调** - 自动验证交易状态并更新订单
- ✅ **签名验证** - 严格验证支付通知的真实性，确保交易安全
- ✅ **客户余额自动充值** - 支付成功后自动为客户账户充值
